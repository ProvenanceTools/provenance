Recording your work with Provenance

For some assignments you'll record your work with the Provenance Recorder, an editor extension that logs how your code comes together. Install it, open the assignment folder, work normally.

The short version

  • It records how your code came together inside the assignment folder. Not your browser, not your other projects, nothing outside that folder.
  • It doesn't look at your code and judge it. There's no "is this AI-written?" detector in it.
  • Nothing is automatic. A person reads the record before anything happens.
  • Copying and pasting your own code around is normal and is treated as normal.
  • If you did the work, the record is the best evidence you have that you did it.

Quick answers

  • Can I copy and paste my own code? Yes. Refactoring, moving functions between files, cutting and re-pasting: all normal.
  • Does it affect my grade? No. It doesn't produce a score.
  • Can I be automatically flagged or reported? No. Every outcome requires a person to read your record first.
  • Does it see my browser or my other projects? No. Only the assignment folder.
  • Does it send anything while I'm working? No. It makes no network requests during a session.
  • Can I read my own log? Yes. It's plain text, in the .provenance/ folder.
  • Which editor should I use? One this course supports.
  • What if I forgot to record part of an assignment? Tell us. A gap you mention is administrative; a gap found later is a conversation.
